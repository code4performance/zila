Zila Lang

A small, readable language that compiles straight to machine code.

What is Zila Lang?

Zila Lang is a compiled, statically typed language with readable syntax, where blocks close with the word end. Its compiler, written in Rust with no dependencies, produces x86-64 programs for Windows and Linux itself: no virtual machine, no garbage collector, no runtime to install. Errors are values, memory is reference-counted, and the same language writes applications, C bindings and a kernel.

Underneath that readable surface sits a practical, static type system: records, enums (with or without data), and structural interfaces, with generics for reusable code. Errors are values, not exceptions — a function that can fail returns T or error, and try propagates failure up the call stack explicitly, so you can always see where a program might fail just by reading its signatures.

Zila Lang doesn't stop at the application layer. The same language can drop into unsafe blocks to dereference raw pointers, declare extern "C" functions, and write inline asm — enough to call into existing C libraries, be called from C, or write a naked interrupt handler, without switching languages or reaching for a separate systems-programming toolkit.

What it is for

A modern language without the overhead: the good features of modern languages, simple to learn, compiled straight to machine code. It was born to work with AI, both as a client and serving a variety of services, with native connections to the main databases, and made for the web, IoT and mobile. It is extensible through packages and open source.

  • AI: clients for models, tools, MCP and RAG, and the services that serve them
  • Services and the web: command-line tools, HTTP servers and APIs
  • Databases: native drivers (PostgreSQL and SQL Server today)
  • Native code: desktop windows, bindings to C libraries, operating-system code
  • Targets in progress: IoT and mobile, not yet built

Design goals

  • Readable by default. Newline-terminated statements, end-delimited blocks, and method chains that read top-to-bottom.
  • Errors you can see. No hidden exceptions — failure is part of a function's return type (T or error), and propagation (try) is explicit at every call site.
  • Native and tiny. Programs compile straight to machine code, with memory freed by reference counting and no runtime to install: see Native compilation. The same compiler builds native windows with the ui library (see the example) and a bootable kernel: Zila Lang OS.
  • Waiting without freezing. async/await, timers, files and TCP run on cooperative tasks: see Async. Real parallelism comes from threads, shared data and sync.Mutex: see Threads.
  • A practical type system. Records, enums (with or without data), and structural interfaces (a type satisfies an interface just by having the right methods — no inheritance, no explicit implements).
  • No surprise costs. Records are copied on assignment and call unless passed ref, a temporary borrow that cannot escape the call; lists and maps are values too, copied lazily (writing to a shared list copies it, writing to your own list does not); there's no borrow checker and no hidden allocation magic.
  • Systems-capable when you need it. Raw pointers, unsafe blocks, C FFI, and inline assembly are part of the language, gated behind explicit syntax rather than bolted on.

Who it's for

Zila Lang is aimed at people who like the explicitness of languages like Go or Rust — typed signatures, errors as values, no hidden control flow — but want a lighter, more conversational syntax day to day. It also targets developers who occasionally need to go low-level: calling a C library, exporting a function for a C caller, or writing a few lines of inline assembly, without leaving the language they write their application code in.

A quick taste

examples/hello.zila
package main

type Customer = record
    id: i32
    name: text
    email: text?
end

func greet(c: Customer) -> text
    return "Hello, {c.name}!"
end

func main()
    var c = Customer{ id: 1, name: "Ana" }
    print(greet(c))

    for i in 1..5
        if i % 2 == 0
            print("{i} is even")
        end
    end
end

Notice the string interpolation ("{c.name}"), the optional field (email: text?), and that every block closes with end instead of braces.
