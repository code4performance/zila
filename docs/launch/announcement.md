# Zila Lang is now open source

**A small, readable language that compiles straight to machine code.**

Zila Lang is a compiled, statically typed language with readable syntax, where blocks close with the word end. Its compiler, written in Rust with no dependencies, produces x86-64 programs for Windows and Linux itself: no virtual machine, no garbage collector, no runtime to install. Errors are values, memory is reference-counted, and the same language writes applications, C bindings and a kernel.

It is for command-line tools and servers, native desktop windows, bindings to C libraries, and operating-system code.

## Why now

Zila Lang has been designed and built with the help of AI, under detailed human direction: people decide what the language is and why, write the rules it follows, and review what comes out. Over 1,000 automated tests pass, but almost nothing has been used outside this process yet. The project is **pre-alpha**, and what it needs most now is people: to try it, break it, and tell us where it is clumsy, confusing or wrong.

## What kind of help is wanted

- **Write real programs** in it and tell us where it was clumsy, confusing or wrong.
- **Try the examples and the libraries** (`web`, `json`, the databases, `ai`) on your own machine, especially on Linux, where the project is least tested.
- **Report bugs** with the smallest program that shows them, and **question design decisions** in an issue.
- **Pick up a `good first issue`** — concrete, scoped tasks are listed on the repository's issue tracker, filtered by that label.
- Improve the documentation, add examples and tests.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) to start; you do not need to know compilers.
